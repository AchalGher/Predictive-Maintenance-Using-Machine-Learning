Predictive Maintenance API

Project Overview

This project predicts equipment failures using machine learning models trained on sensor data. By analyzing patterns in sensor readings, the model can classify whether a failure is likely to occur soon.

How It Works

1. The model is trained using a RandomForestClassifier on sensor data.
2. The input data is scaled using StandardScaler.
3. The model predicts whether the equipment is likely to fail (1) or not (0) based on sensor values.

API Usage

1. Input sensor data through the form below.
2. The request is sent to the backend FastAPI model.
3. The model returns a prediction result (1 for failure, 0 for no failure).
